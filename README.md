# GAS-SpreadSheet-ChatSystem 

#### GoogleAppScriptを使用したチャットアプリ。
スプレッドシートをデータベースとして利用し、アカウント制によるメッセージ機能を実装。

このプロジェクトは、Google Apps Script (GAS) を用いて構築されたシンプルなリアルタイムチャットアプリケーションです。特筆すべきは、Google スプレッドシートをバックエンドのデータベースとして活用している点です。これにより、特別なデータベースサーバーやクラウドサービスの契約なしに、手軽にチャットシステムを構築・運用できます。
<br> 
### 主な機能
 * リアルタイムチャット: メッセージの送受信をほぼリアルタイムで反映します。
 * Google スプレッドシートをデータベースに: 全てのチャット履歴は指定されたGoogleスプレッドシートに保存されます。
 * Google Apps Scriptによるサーバーロジック: スプレッドシートのデータの読み書き、HTMLへの描画をGASが担当します。
 * シンプルなUI: 直感的なインターフェースで、誰でも簡単に利用できます。

### 使用技術
このプロジェクトでは、以下の技術スタックを採用しています。
 #### フロントエンド (クライアントサイド)
   * HTML, CSS: アプリケーションの構造とスタイリング
   * JavaScript: クライアントサイドのインタラクティブな動作
 #### バックエンド (サーバーサイド)
   * Google Apps Script (GAS):
     * Googleスプレッドシートとの連携（データの読み書き）
     * ウェブアプリとしてのフロントエンドファイルの配信
     * クライアントからのリクエスト処理
   * Google Sheets:
     * チャットメッセージの保存、管理
### プロジェクトの狙い / 工夫した点
 * 超低コスト・高可用性: 既存のGoogleアカウントとスプレッドシートがあれば、追加費用なしでチャットシステムを構築・運用できます。Googleのインフラ上で動作するため、高い可用性も期待できます。
 * データベース不要の利便性: データベースのセットアップや管理の知識がなくても、日常的に使われているスプレッドシートをデータストアとして利用できるため、開発・運用が容易です。
 * GASの可能性の探求: GASのWebアプリ機能とスプレッドシート連携機能を最大限に活用し、どこまで本格的なアプリケーションが構築できるかを探求しました。
### セットアップ方法 (開発者向け)
このプロジェクトをあなたのGoogle Workspace環境で動かすための手順です。

#### 1. Google スプレッドシートの準備
 * 新しいGoogleスプレッドシートを作成し、任意の名前を付けます（例: Chat Log）。
 * スプレッドシートのシート名を確認します（デフォルトはシート1）。後でGASコード内で使用します。
 * 1行目をヘッダーとして、以下の列名を設定することを推奨します（必須ではありませんが、コードと整合性を保つため）：
   * Timestamp (日付/時間)
   * User (ユーザー名)
   * Message (メッセージ内容)

#### 2. Google Apps Script の設定
 * Google ドライブから新しい Google Apps Script プロジェクトを作成します。
 * 以下のファイルをGASプロジェクトにコピーします。
   * Code.gs
   * index.html (またはフロントエンドファイル全体)
 * Code.gs 内で、使用するスプレッドシートの ID と シート名 を設定します。
```bash
   // Code.gs 内の例
const SPREADSHEET_ID = 'あなたのスプレッドシートID'; // GoogleスプレッドシートのURLから取得
const SHEET_NAME = 'シート1'; // 使用するシートの名前
```

 * GASプロジェクトをウェブアプリとしてデプロイします。
   * デプロイの種類: 「ウェブアプリ」を選択
   * 実行ユーザー: 「自分」
   * アクセスできるユーザー: 「自分のみ」または「Google アカウントを持つ全員」など、テスト環境に合わせて設定。
   * デプロイするたびに新しいバージョンとして保存することをお勧めします。
 * デプロイ後、発行されるウェブアプリのURLを控えておきます。このURLがチャットアプリのアクセスポイントになります。

#### 3. アプリケーションの動作確認
 * 控えておいたウェブアプリのURLをブラウザで開きます。
 * チャットメッセージを送信し、スプレッドシートにデータが記録されることを確認してください。
